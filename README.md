# Arsh Kamal — Portfolio

A responsive personal developer portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Add your GitHub
Search/find your GitHub username, then replace every:
`YOUR_GITHUB_LINK_HERE`

You can also replace the project placeholders:
- YOUR_SPOTIFY_PROJECT_LINK
- YOUR_SPOTIFY_GITHUB_LINK
- YOUR_PORTFOLIO_GITHUB_LINK
- YOUR_CALCULATOR_DEMO
- YOUR_CALCULATOR_GITHUB_LINK
- YOUR_CHAT_DEMO
- YOUR_CHAT_GITHUB_LINK

## Files
- `index.html` — page structure/content
- `style.css` — complete styling/responsive design
- `script.js` — menu, theme switcher and reveal animations
- `assets/profile.jpg` — profile photo
- `assets/Arsh-Kamal-Resume.pdf` — resume
